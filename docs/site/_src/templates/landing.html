Specs live in your code

Specifications are @custom:strata NatSpec annotations: no imports, no stub functions, no separate spec language. solc is used only to produce the AST, so the compiler stays untouched.

One binary

The strataSolidity binary runs the whole pipeline. It invokes solc, parses the JSON AST into typed Lean structures, translates it, and verifies.

Built on Strata

Contracts are translated into Laurel, Strata’s intermediate verification language, and checked by Strata Core with an SMT solver.

Get started

Build from source. You need Lean 4 (via elan), solc, and z3 on your PATH. The Strata framework comes in as a git submodule.
